# Thalassa — Farol das Marés

Esta pasta contém as artes progressivas da maravilha Thalassa.

Coloque aqui os seis arquivos WebP transparentes do pacote `thalassa-etapas-webp.zip`:

- `etapa-0.webp` — fundações
- `etapa-1.webp` — construção inicial
- `etapa-2.webp` — torre em desenvolvimento
- `etapa-3.webp` — construção avançada com andaimes
- `etapa-4.webp` — últimos trabalhos
- `etapa-5.webp` — farol concluído, sem andaimes

O componente `src/components/game/Wonder.tsx` carrega automaticamente `/thalassa/etapa-N.webp` conforme o número de etapas construídas.
